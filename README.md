# 💼 Dev Profile Card

Um projeto simples e elegante que apresenta um cartão de perfil com informações de um desenvolvedor, feito como desafio do site [Frontend Mentor](https://www.frontendmentor.io/).

## 📸 Preview

![Preview do Projeto](./screenshot.png)

---

## 🧰 Tecnologias Utilizadas

- **HTML5** – Estrutura semântica da página
- **CSS3** – Estilização com foco em responsividade e visual moderno
- **Google Fonts** – Tipografia personalizada

---

## 🎯 Funcionalidades

- Exibição de imagem de perfil
- Nome, localização e descrição profissional
- Botões de navegação para redes sociais (Github, LinkedIn, Instagram)
- Design responsivo e centrado

---

## 🗂 Estrutura de Arquivos

```bash
📁 dev-profile-card/
├── index.html
├── style.css
└── README.md
```

---

## 🧪 Como Usar

1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/dev-profile-card.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd dev-profile-card
   ```

3. Abra o arquivo `index.html` no navegador.

---

## ✍️ Personalização

Você pode modificar facilmente as informações no arquivo `index.html` para:

- Atualizar seu nome e localização
- Substituir a imagem de perfil
- Alterar os links de redes sociais
- Customizar as cores e fontes no `style.css`
